# Hi, I’m Bob. I build things you can step into.

I’m interested in what happens when research, storytelling and interactive design meet. I use AI, code and a lot of experimentation to turn ideas into experiences people can explore.

I care about the moment something clicks for the person using it. That means building, showing people, listening closely and trying again.

## Start exploring

- [Bob’s Room](https://bobshenruililin.github.io/bobs-room/): my personal website as a walkable pixel room, filled with interests, stories and places I call home.
- [When lives span a border](https://bobshenruililin.github.io/jamie-crossing-lives-site/): an interactive companion to Jamie Ko’s research on cross-border lives. Research and presentation by Jamie; visual support by me.
- [Crossing Lives](https://bobshenruililin.github.io/crossing-lives/): a separate game exploring everyday choices between Hong Kong and Shenzhen.

## Currently building: Asterwind

A floating academy, a handmade paper world, and familiar situations that ask how we lead and work with others. Still in development, and a project I’m especially excited about.

More worlds, questions and experiments to come.
